## 为什么需要Promise


┌─────────────────────────────────────────────────────────────────────────┐
│                         第一性原理追问链                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Q1: 为什么需要 Promise？                                                │
│      ↓                                                                  │
│  A1: 因为回调函数有缺陷（回调地狱、控制反转、错误分散）                    │
│      ↓                                                                  │
│  Q2: 为什么会有回调函数？                                                │
│      ↓                                                                  │
│  A2: 因为 JavaScript 是单线程，需要异步处理耗时操作                       │
│      ↓                                                                  │
│  Q3: 为什么 JavaScript 是单线程？                                        │
│      ↓                                                                  │
│  A3: 因为 JS 诞生于浏览器，操作 DOM 需要避免多线程同步问题                │
│                                                                         │
│  ═══════════════════════════════════════════════════════════════════   │
│                                                                         │
│  根本原因：单线程 + 需要处理耗时操作 = 必须异步                           │
│  核心矛盾：异步代码的可读性、可控性、可维护性                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
