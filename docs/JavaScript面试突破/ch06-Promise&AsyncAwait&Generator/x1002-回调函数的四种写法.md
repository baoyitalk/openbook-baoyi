什么是回调函数
把函数作为参数传给另一个函数，让它在合适时机调用


## 写法1： 单独定义回调函数
```js
  

// 1. 定义回调函数（可以叫任意名字）

function printResult(res) {

console.log(`结果是：${res}`);

}

  

// 2. 定义主函数（接收回调的参数可以叫任意名字）

function calculate(a, b, callback) {

const sum = a + b;

// 3. 主函数内部调用回调函数

callback(sum);

}

  

// 调用：把回调函数传给主函数

calculate(2, 3, printResult); // 输出：结果是：5
```





## 写法2：匿名函数作为回调
不用单独定义回调函数，直接把匿名函数作为参数传入

```js
function calculate(a, b, callback) {

callback(a + b);

}

  

// 匿名函数作为回调（没有函数名，直接传）
// 有个明显特征 回调函数的参数不是主动传的是主函数计算后的结果就叫做回传回调的意思

calculate(2, 3, function(res) {

console.log(`结果是：${res}`);

});

```


### 拆解 写法2 

```
`res` 是回调函数的参数，它接收的是 `calculate` 函数内部传给它的值。

执行流程是这样的：

1. 调用 `calculate(2, 3, function(res) {...})`
2. 进入 `calculate` 函数，`a=2`, `b=3`, `callback=那个匿名函数`
3. 执行 `callback(a + b)`，也就是 `callback(5)`
4. 这时 `5` 就传给了匿名函数的 `res` 参数
5. 所以 `res = 5`，输出 `结果是: 5`


```

### 回调函数底层逻辑 
简单说：`res` 不是你传进去的，是 `calculate` 函数算完后"回传"给你的结果。这就是"回调"的意思——你给我一个函数，我算完了再调用它把结果给你。



## 写法3： 箭头函数写法
用箭头函数 代替匿名函数，语法更精简

```js
// 定义主函数
function calculate(a, b, callback) {
// 主函数内部调用
callback(a + b);

}


// 箭头函数作为回调（最简洁的写法）

calculate(2, 3, res => console.log(`结果是：${res}`));
```

拆解

```js

// 这三种写法完全等价
res => console.log(res)           // 单参数可省略括号
(res) => console.log(res)         // 加括号也行
(res) => { console.log(res) }     // 加花括号也行
function(res) { console.log(res) } // 传统写法
```

## 写法 4：甚至可以 “反向”（主函数是匿名函数）

回调函数的核心是 “函数传参”，主函数也可以是匿名的，逻辑依然成立：

```js

// 主函数是匿名函数，回调函数是 printResult

const calculate = function(a, b, callback) {

callback(a + b);

};

  

function printResult(res) {

console.log(`结果是：${res}`);

}

  

calculate(2, 3, printResult);
```
