对，回调也能并行，只是写起来丑一点。

```javascript
let count = 0
let results = {}

function done() {
  count++
  if (count === 3) {
    console.log(results) // 三个都完成了
  }
}

getUser((user) => {
  results.user = user
  done()
})

getOrders((orders) => {
  results.orders = orders
  done()
})

getDetail((detail) => {
  results.detail = detail
  done()
})
```

三个请求同时发出，总时间 = 1 秒。 （js是单线程 但是延迟0.001感知不出 勉强说并行）

## 对比

```javascript
// Promise.all 一行搞定
Promise.all([getUser(), getOrders(), getDetail()])
  .then(([user, orders, detail]) => { ... })
```

功能一样，但回调方式需要自己手动维护计数器和结果收集。Promise.all 把这些脏活封装好了。
