## 拆解1：-红绿灯这个场景里面 Promise存在的意义

await 要接收Promise包裹的对象 delay这个约定成俗的延迟函数要返回一个Promise对象

```js
// 返回 Promise 的 API → 直接 await
await fetch("https://api.example.com");
await response.json();
await User.findById(id);

// 不返回 Promise 的 API → 需要包装
function delay(time) {
    return new Promise(resolve => setTimeout(resolve, time));
}
await delay(1000);

```

|API|返回 Promise？|需要包装？|示例|
|---|---|---|---|
|fetch|✅ 是|❌ 不需要|`await fetch(url)`|
|response.json()|✅ 是|❌ 不需要|`await response.json()`|
|setTimeout|❌ 否|✅ 需要|`await delay(1000)`|
|fs.readFile|❌ 否|✅ 需要|`await readFile(path)`|
|数据库查询|✅ 是|❌ 不需要|`await User.find()`|



# 纯Promise实现红绿灯

好的！用纯 Promise 实现红绿灯：
## 案例1：

```javascript
function delay(fn, time) {
    return new Promise((resolve) => {
        setTimeout(() => {
            resolve(fn());
        }, time);
    });
}

function light() {
    delay(() => console.log("red"), 3000)
        .then(() => delay(() => console.log("green"), 2000))
        .then(() => delay(() => console.log("yellow"), 1000))
        .then(() => light());  // 递归循环
}

light();
```

## 执行流程

```javascript
function light() {
    delay(() => console.log("red"), 3000)      // 3秒后输出 red
        .then(() => delay(() => console.log("green"), 2000))   // 再2秒后输出 green
        .then(() => delay(() => console.log("yellow"), 1000))  // 再1秒后输出 yellow
        .then(() => light());  // 重新开始
}

// 时间线：
// 0s    → 开始
// 3s    → red
// 5s    → green
// 6s    → yellow
// 6s    → 重新开始
// 9s    → red
// 11s   → green
// 12s   → yellow
// ...循环
```

## 对比：Promise vs async/await

```javascript
// 方式1：纯 Promise（链式调用）
function light1() {
    delay(() => console.log("red"), 3000)
        .then(() => delay(() => console.log("green"), 2000))
        .then(() => delay(() => console.log("yellow"), 1000))
        .then(() => light1());
}

// 方式2：async/await（看起来更清晰）
async function light2() {
    await delay(() => console.log("red"), 3000);
    await delay(() => console.log("green"), 2000);
    await delay(() => console.log("yellow"), 1000);
    await light2();
}

// 两者完全等价！
```

## 不用递归，用无限循环

```javascript
function delay(fn, time) {
    return new Promise((resolve) => {
        setTimeout(() => {
            fn();
            resolve();
        }, time);
    });
}

function lightOnce() {
    return delay(() => console.log("red"), 3000)
        .then(() => delay(() => console.log("green"), 2000))
```

## 用 Promise 链处理错误

```javascript
function delay(fn, time) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            try {
                fn();
                resolve();
            } catch (error) {
                reject(error);
            }
        }, time);
    });
}

function light() {
    delay(() => console.log("red"), 3000)
        .then(() => delay(() => console.log("green"), 2000))
        .then(() => delay(() => console.log("yellow"), 1000))
        .then(() => light())
        .catch((error) => {
            console.error("出错了:", error);
        });
}

light();
```

## 数组 + reduce 实现

```javascript
function delay(color, time) {
    return new Promise((resolve) => {
        setTimeout(() => {
            console.log(color);
            resolve();
        }, time);
    });
}

function light() {
    const lights = [
        { color: "red", time: 3000 },
        { color: "green", time: 2000 },
        { color: "yellow", time: 1000 }
    ];

    lights.reduce((promise, light) => {
        return promise.then(() => delay(light.color, light.time));
    }, Promise.resolve())
    .then(light);
}

light();
```

## Promise 链的本质

```javascript
// Promise 链的执行顺序
new Promise((resolve) => {
    setTimeout(() => {
        console.log("red");
        resolve();  // ← 完成后，执行下一个 then
    }, 3000);
})
.then(() => {
    return new Promise((resolve) => {
        setTimeout(() => {
            console.log("green");
            resolve();  // ← 完成后，执行下一个 then
        }, 2000);
    });
})
.then(() => {
    return new Promise((resolve) => {
        setTimeout(() => {
            console.log("yellow");
            resolve();  // ← 完成后，执行下一个 then
        }, 1000);
    });
})
.then(() => {
    // 重新开始
    light();
});
```

## 总结

```javascript
// 核心代码（纯 Promise）
function delay(fn, time) {
    return new Promise((resolve) => {
        setTimeout(() => {
            fn();
            resolve();
        }, time);
    });
}

function light() {
    delay(() => console.log("red"), 3000)
        .then(() => delay(() => console.log("green"), 2000))
        .then(() => delay(() => console.log("yellow"), 1000))
        .then(light);
}

light();
```

### 关键点

1. **delay 返回 Promise** → 可以链式调用 `.then()`
2. **then 里返回新的 Promise** → 继续链式调用
3. **最后一个 then 调用 light()** → 无限循环
4. **Promise 链保证顺序执行** → red → green → yellow → 循环

这就是纯 Promise 实现！比 async/await 稍微复杂一点，但原理更清晰。
