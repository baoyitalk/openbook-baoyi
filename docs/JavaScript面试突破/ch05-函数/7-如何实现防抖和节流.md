
在实际业务开发中，会遇到一些频繁触发的事件，比如浏览器窗口的resize、scroll等，处于性能考虑，需要减少触发数量，或者延迟触发事件的时间等，因此就用到了防抖（debounce）和节流（throttle）


# 防抖

防抖的原理就是：用户可以尽管触发事件，但是一定在事件触发n秒后才执行。如果在此期间又触发了这个事件，那么就从新触发的时间点算起，n秒后才执行。
防抖的主要作用就是出于性能考虑延迟事件执行。

防抖是根据延迟的时间点触发事件的。我们可以如下实现：
## 案例1：

```js
// 防抖函数定义
function debounce(cb, delay = 250) {
  let timeout;
  return (...args) => {
    clearTimeout(timeout);
    timeout = setTimeout(() => {
      cb(...args);
    }, delay);
  };
}

// 模拟搜索函数
function search(keyword) {
  console.log(`执行搜索: "${keyword}"`);
}

// 用防抖包装搜索函数
const debouncedSearch = debounce(search, 500);

// 模拟用户快速输入
console.log('开始模拟输入...\n');

console.log('[0ms] 输入: h');
debouncedSearch('h');

setTimeout(() => {
  console.log('[100ms] 输入: he');
  debouncedSearch('he');
}, 100);

setTimeout(() => {
  console.log('[200ms] 输入: hel');
  debouncedSearch('hel');
}, 200);

setTimeout(() => {
  console.log('[300ms] 输入: hell');
  debouncedSearch('hell');
}, 300);

setTimeout(() => {
  console.log('[400ms] 输入: hello');
  debouncedSearch('hello');
}, 400);

// 停止输入，等待防抖触发
setTimeout(() => {
  console.log('\n[900ms] 停止输入，等待结果...');
}, 900);
```


# 节流
节流是以时间段为节点， 如果事件触发在这个时间段内，那么就只触发一次。
有两种实现方法：
- 使用定时器
- 使用时间戳

## 使用定时器

使用标识变量shouldWait， 如果事件执行了则不再执行任何操作，否则，执行事件，并且修改标识变量shouleWait
