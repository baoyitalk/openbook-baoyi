## 一、第一性原理：为什么需要拷贝？

### 1.1 根本问题

```
当我们把一个对象赋值给另一个变量时，发生了什么？

const obj1 = { name: 'Alice', age: 25 };
const obj2 = obj1;

obj2.name = 'Bob';
console.log(obj1.name);  // 'Bob' 😱 obj1 也被改了！

根本原因：obj2 和 obj1 指向【同一块内存】
```

### 1.2 拷贝的本质需求

```
┌─────────────────────────────────────────────────────────────────┐
│                       拷贝的本质需求                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   我们希望：修改新对象时，【不影响】原对象                        │
│                                                                 │
│   这就需要：创建一个【独立的副本】                               │
│                                                                 │
│   问题来了：                                                    │
│   ├── 只复制第一层？ → 浅拷贝                                   │
│   └── 递归复制所有层？ → 深拷贝                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 三、赋值、浅拷贝、深拷贝的本质区别

### 3.1 三者对比图解

```
┌─────────────────────────────────────────────────────────────────┐
│              赋值 vs 浅拷贝 vs 深拷贝                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   原对象: { name: 'Alice', address: { city: 'NYC' } }           │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │                       赋值                               │  │
│   │   obj2 = obj1                                           │  │
│   │                                                         │  │
│   │   obj1 ──────┐                                         │  │
│   │              ├──> { name, address: ──> { city } }      │  │
│   │   obj2 ──────┘                                         │  │

│   │   完全共享，改任何属性都互相影响                         │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │                       浅拷贝                             │  │
│   │   obj2 = { ...obj1 }                                    │  │
│   │                                                         │  │
│   │   obj1 ──> { name, address: ─┐                         │  │
│   │                              ├──> { city }              │  │

│   │                                                         │  │

│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │                       深拷贝                             │  │
│   │   obj2 = deepClone(obj1)                                │  │
│   │                                                         │  │
│   │   obj1 ──> { name, address: ──> { city } }              │  │
│   │                                                         │  │
│   │   obj2 ──> { name, address: ──> { city } }              │  │
│   │                                                         │  │
│   │   完全独立，互不影响                                     │  │

│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 代码验证

```javascript
const obj1 = { 
  name: 'Alice', 
  age: 25, 
  address: { city: 'New York' } 
};

// 赋值
const obj2 = obj1;
obj2.age = 30;
obj2.address.city = 'Los Angeles';
console.log(obj1.age);           // 30 ❌ 被影响
console.log(obj1.address.city);  // 'Los Angeles' ❌ 被影响

// 浅拷贝
const obj3 = { ...obj1 };
obj3.age = 35;
obj3.address.city = 'Chicago';

console.log(obj1.address.city);  // 'Chicago' ❌ 被影响（嵌套共享）

// 深拷贝
const obj4 = JSON.parse(JSON.stringify(obj1));
obj4.age = 40;
obj4.address.city = 'Seattle';
console.log(obj1.age);           // 30 ✅ 不受影响
console.log(obj1.address.city);  // 'Chicago' ✅ 不受影响
```

## 四、浅拷贝实现方法

### 4.1 浅拷贝的定义

> 浅拷贝是按位拷贝对象，它会创建一个新对象，这个对象有着原始对象属性值的精确拷贝。如果属性是基本类型，拷贝的就是值；如果属性是引用类型，拷贝的是内存地址。

### 4.2 三种实现方式

```javascript
// 方法1: 遍历 key/value 赋值
function shallowCopy1(obj) {
  if (typeof obj !== 'object' || obj === null) return obj;
  
  const result = Array.isArray(obj) ? [] : {};
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      result[key] = obj[key];
    }
  }
  return result;
}

// 方法2: Object.assign()
function shallowCopy2(obj) {
  return Object.assign({}, obj);
}

// 方法3: 展开运算符 ...
function shallowCopy3(obj) {
  return { ...obj };
}

// 数组的浅拷贝方法
const arr = [1, 2, { a: 3 }];
const arr1 = arr.slice();        // slice()
const arr2 = arr.concat();       // concat()
const arr3 = [...arr];           // 展开运算符
const arr4 = Array.from(arr);    // Array.from()
```

### 4.3 浅拷贝效果验证

```javascript
const obj1 = {
  name: '张三',
  age: 8,
  pal: ['王五', '王六', '王七']
};

const obj3 = shallowCopy1(obj1);

obj3.name = '李四';
obj3.pal[0] = '王麻子';

console.log("obj1", obj1);
// { age: 8, name: '张三', pal: ['王麻子', '王六', '王七'] }
//                             ↑ 嵌套数组被影响了！

console.log("obj3", obj3);
// { age: 8, name: '李四', pal: ['王麻子', '王六', '王七'] }
```

## 五、深拷贝实现方法

### 5.1 方法一：基础递归实现

**核心思路：遍历对象，遇到引用类型就递归复制**

```javascript
function deepCopy(obj) {
  // 1. 处理 null 和基本类型
  if (obj === null || typeof obj !== 'object') {
    return obj;
  }
  
  // 2. 处理数组和对象
  let newObj = Array.isArray(obj) ? [] : {};
  
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      // 递归调用
      newObj[key] = deepCopy(obj[key]);
    }
  }
  
  return newObj;
}
```

**递归过程图解：**

```
┌─────────────────────────────────────────────────────────────────┐
│                    递归深拷贝过程                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   原对象: { name: 'test', main: { a: 1, b: 2 }, arr: [1, 2] }  │
│                                                                 │
│   deepCopy(obj)                                                │
│       │                                                        │
│       ├── name: 'test' → 基本类型，直接返回                    │
│       │                                                        │
│       ├── main: { a: 1, b: 2 } → 对象，递归调用                │
│       │       │                                                │
│       │       ├── a: 1 → 基本类型，直接返回                    │
│       │       └── b: 2 → 基本类型，直接返回                    │
│       │                                                        │
│       └── arr: [1, 2] → 数组，递归调用                         │
│               │                                                │
│               ├── [0]: 1 → 基本类型，直接返回                  │
│               └── [1]: 2 → 基本类型，直接返回                  │
│                                                                 │
│   最终返回完全独立的新对象                                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 方法二：处理更多类型

```javascript
function deepCopy(target) {
  // 基本类型直接返回
  if (target === null || typeof target !== 'object') {
    return target;
  }
  
  // 处理 Date
  if (target instanceof Date) {
    return new Date(target.getTime());
  }
  
  // 处理 RegExp
  if (target instanceof RegExp) {
    return new RegExp(target);
  }
  
  // 处理数组
  if (Array.isArray(target)) {
    return target.map(item => deepCopy(item));
  }
  
  // 处理普通对象
  const newTarget = Object.create(null);  // 创建纯净对象
  for (const key in target) {
    if (target.hasOwnProperty(key)) {
      newTarget[key] = deepCopy(target[key]);
    }
  }
  return newTarget;
}
```

### 5.3 方法三：使用 Map 解决循环引用 ⭐

**问题：如果对象自己引用自己怎么办？**

```javascript
const obj = { name: 'test' };
obj.self = obj;  // 循环引用

deepCopy(obj);  // ❌ 会无限递归，栈溢出！
```

**解决方案：用 Map 记录已拷贝的对象**

```javascript
function deepCopy(target, hash = new Map()) {
  // 基本类型直接返回
  if (target === null || typeof target !== 'object') {
    return target;
  }
  
  // 🔑 关键：检查是否已经拷贝过
  if (hash.has(target)) {
    return hash.get(target);  // 直接返回之前的拷贝
  }
  
  // 处理 Date
  if (target instanceof Date) {
    return new Date(target.getTime());
  }
  
  // 处理 RegExp
  if (target instanceof RegExp) {
    return new RegExp(target);
  }
  
  // 创建新对象/数组
  const newTarget = Array.isArray(target) ? [] : Object.create(null);
  
  // 🔑 关键：存入 Map，建立映射关系
  hash.set(target, newTarget);
  
  // 递归拷贝属性
  for (const key in target) {
    if (target.hasOwnProperty(key)) {
      newTarget[key] = deepCopy(target[key], hash);  // 传递 hash
    }
  }
  
  return newTarget;
}
```

**循环引用处理图解：**

```
┌─────────────────────────────────────────────────────────────────┐
│                  Map 解决循环引用                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   const obj = { name: 'test' };                                │
│   obj.self = obj;                                              │
│                                                                 │
│   deepCopy(obj, hash)                                          │
│       │                                                        │
│       ├── hash.has(obj)? → No                                  │
│       ├── 创建 newObj = {}                                     │
│       ├── hash.set(obj, newObj)  // 记录映射                   │
│       │                                                        │
│       ├── 拷贝 name: 'test'                                    │
│       │                                                        │
│       └── 拷贝 self: obj                                       │
│               │                                                │
│               └── deepCopy(obj, hash)                          │
│                       │                                        │
│                       └── hash.has(obj)? → Yes! ✅             │
│                           return hash.get(obj)                 │
│                           // 返回之前创建的 newObj              │
│                           // 避免无限递归！                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.4 方法四：WeakMap 优化内存 ⭐⭐

```javascript
function deepCopy(target, hash = new WeakMap()) {
  // 基本类型直接返回
  if (target === null || typeof target !== 'object') {
    return target;
  }
  
  // 检查循环引用
  if (hash.has(target)) {
    return hash.get(target);
  }
  
  // 处理特殊对象
  if (target instanceof Date) {
    return new Date(target.getTime());
  }
  if (target instanceof RegExp) {
    return new RegExp(target);
  }
  
  // 创建新对象
  const newTarget = Array.isArray(target) ? [] : Object.create(null);
  hash.set(target, newTarget);
  
  // 递归拷贝
  for (const key in target) {
    if (target.hasOwnProperty(key)) {
      newTarget[key] = deepCopy(target[key], hash);
    }
  }
  
  return newTarget;
}
```

**为什么用 WeakMap 而不是 Map？**

```
┌─────────────────────────────────────────────────────────────────┐
│                   Map vs WeakMap                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   Map                              WeakMap                      │
│   ───                              ───────                      │
│   键可以是任意类型                  键只能是对象                  │
│   强引用，不会被垃圾回收            弱引用，可以被垃圾回收        │
│   有 size 属性                     没有 size 属性               │
│   可以遍历                         不可遍历                     │
│                                                                 │
│   ════════════════════════════════════════════════════════════ │
│                                                                 │
│   使用 WeakMap 的好处：                                         │
│                                                                 │
│   当原对象被回收时，WeakMap 中的对应条目也会被自动回收           │
│   更适合大量数据的深拷贝，不会造成内存泄漏                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.5 终极版：处理所有类型 ⭐⭐⭐

```javascript
function deepClone(obj, hash = new WeakMap()) {
  // 1. 基本类型和 null 直接返回
  if (obj === null || typeof obj !== 'object') {
    return obj;
  }
  
  // 2. 处理循环引用
  if (hash.has(obj)) {
    return hash.get(obj);
  }
  
  // 3. 处理 Date
  if (obj instanceof Date) {
    return new Date(obj.getTime());
  }
  
  // 4. 处理 RegExp
  if (obj instanceof RegExp) {
    return new RegExp(obj);
  }
  
  // 5. 处理 Map
  if (obj instanceof Map) {
    const result = new Map();
    hash.set(obj, result);
    obj.forEach((value, key) => {
      result.set(deepClone(key, hash), deepClone(value, hash));
    });
    return result;
  }
  
  // 6. 处理 Set
  if (obj instanceof Set) {
    const result = new Set();
    hash.set(obj, result);
    obj.forEach(value => {
      result.add(deepClone(value, hash));
    });
    return result;
  }
  
  // 7. 处理数组
  if (Array.isArray(obj)) {
    const result = [];
    hash.set(obj, result);
    obj.forEach((item, index) => {
      result[index] = deepClone(item, hash);
    });
    return result;
  }
  
  // 8. 处理普通对象
  const result = Object.create(Object.getPrototypeOf(obj));
  hash.set(obj, result);
  
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      result[key] = deepClone(obj[key], hash);
    }
  }
  
  // 9. 处理 Symbol 键
  const symbolKeys = Object.getOwnPropertySymbols(obj);
  for (const symKey of symbolKeys) {
    result[symKey] = deepClone(obj[symKey], hash);
  }
  
  return result;
}
```

## 六、JSON 方法的坑

### 6.1 JSON.parse(JSON.stringify()) 的局限性

```javascript
// 简单场景可以用
const obj = { a: 1, b: { c: 2 } };
const copy = JSON.parse(JSON.stringify(obj));  // ✅ 可以
```

### 6.2 七大缺陷

```
┌─────────────────────────────────────────────────────────────────┐
│              JSON.parse(JSON.stringify()) 的坑                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. 函数丢失                                                   │
│      { fn: () => {} }  →  {}                                   │
│                                                                 │
│   2. undefined 丢失                                             │
│      { a: undefined }  →  {}                                   │
│                                                                 │
│   3. Symbol 丢失                                                │
│      { [Symbol()]: 1 }  →  {}                                  │
│                                                                 │
│   4. Date 变成字符串                                            │
│      { d: new Date() }  →  { d: "2024-01-01T00:00:00.000Z" }   │
│                                                                 │
│   5. RegExp 变成空对象                                          │
│      { r: /abc/ }  →  { r: {} }                                │
│                                                                 │
│   6. NaN/Infinity 变成 null                                    │
│      { n: NaN, i: Infinity }  →  { n: null, i: null }          │
│                                                                 │
│   7. 不支持循环引用                                             │
│      obj.self = obj  →  ❌ TypeError                           │
│                                                                 │
│   8. Map/Set 变成空对象                                         │
│      { m: new Map() }  →  { m: {} }                            │
│                                                                 │
│   9. 原型链丢失                                                 │
│      new Person()  →  普通对象 {}                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.2 面试题2：实现深拷贝（处理循环引用）

```javascript
// 手写深拷贝（必背版本）
function deepClone(obj, hash = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (hash.has(obj)) return hash.get(obj);
  
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  
  const result = Array.isArray(obj) ? [] : {};
  hash.set(obj, result);
  
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      result[key] = deepClone(obj[key], hash);
    }
  }
  
  return result;
}
```

### 7.3 面试题3：判断输出

```javascript

obj2.b.c = 20;

// 答案：
// obj1.a = 1   (基本类型，独立)

```

## 📊 总结对比表

| 特性 | 赋值 | 浅拷贝 | 深拷贝 |
|------|------|--------|--------|
| 是否新对象 | ❌ 同一个 | ✅ 新对象 | ✅ 新对象 |
| 第一层独立 | ❌ | ✅ | ✅ |
| 嵌套层独立 | ❌ | ❌ | ✅ |
| 性能 | 最快 | 快 | 慢 |
| 实现复杂度 | - | 简单 | 复杂 |

## 🎯 核心奥义（一句话总结）

> **深浅拷贝的本质是「复制的是值还是地址」—— 基本类型存值在栈中所以天然独立，引用类型存地址在栈、存值在堆所以共享内存；浅拷贝只复制第一层地址，深拷贝递归复制所有层直到遇到基本类型为止。理解了内存模型，就理解了为什么需要深拷贝。**

## 深拷贝递归原理图解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         深拷贝的递归本质                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   原对象:                                                                   │
│   {                                                                         │
│     name: 'test',        ← 基本类型                                         │
│     info: {              ← 引用类型，需要递归                                │
│       age: 25,           ← 基本类型                                         │
│       addr: {            ← 引用类型，需要递归                                │
│         city: 'NYC'      ← 基本类型                                         │
│       }                                                                     │
│     }                                                                       │
│   }                                                                         │
│                                                                             │
│   ═══════════════════════════════════════════════════════════════════════  │
│                                                                             │
│   递归拷贝过程:                                                              │
│                                                                             │
│   deepClone(obj)                                                            │
│       │                                                                     │
│       ├─→ name: 'test'                                                      │
│       │      │                                                              │
│       │      └─→ typeof === 'string' → 基本类型 → 直接返回 'test' ✅        │
│       │                                                                     │
│       └─→ info: { age: 25, addr: {...} }                                   │
│              │                                                              │
│              └─→ typeof === 'object' → 引用类型 → 递归调用 deepClone()      │
│                      │                                                      │
│                      ├─→ age: 25                                           │
│                      │      │                                              │
│                      │      └─→ 基本类型 → 直接返回 25 ✅                   │
│                      │                                                      │
│                      └─→ addr: { city: 'NYC' }                             │
│                             │                                              │
│                             └─→ 引用类型 → 再次递归 deepClone()             │
│                                    │                                       │
│                                    └─→ city: 'NYC'                         │
│                                           │                                │
│                                           └─→ 基本类型 → 返回 'NYC' ✅     │
│                                                                             │
│   终止条件: 遇到基本类型就停止递归，直接返回值                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 循环引用问题图解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          循环引用问题                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   const obj = { name: 'test' };                                            │
│   obj.self = obj;  // 自己引用自己                                          │
│                                                                             │
│                    ┌─────────────────┐                                      │
│                    │  obj            │                                      │
│                    │  ┌───────────┐  │                                      │
│                    │  │name:'test'│  │                                      │
│                    │  ├───────────┤  │                                      │
│            ┌───────│──│ self: ────│──┘                                      │
│            │       │  └───────────┘                                         │
│            │       └─────────────────┘                                      │
│            │               ▲                                                │
│            └───────────────┘  循环引用!                                      │
│                                                                             │
│   ═══════════════════════════════════════════════════════════════════════  │
│                                                                             │
│   不处理循环引用会怎样？                                                     │
│                                                                             │
│   deepClone(obj)                                                            │
│       └─→ deepClone(obj.self)      // self 就是 obj                        │
│               └─→ deepClone(obj.self.self)   // 还是 obj                   │
│                       └─→ deepClone(obj.self.self.self)  // 无限循环...    │
│                               └─→ ...                                      │
│                                   └─→ 💥 栈溢出!                           │
│                                                                             │
│   ═══════════════════════════════════════════════════════════════════════  │
│                                                                             │
│   解决方案: 用 WeakMap 记录已拷贝的对象                                      │
│                                                                             │
│   WeakMap: { obj → newObj }  // 原对象 → 新对象 的映射                      │
│                                                                             │
│   deepClone(obj, weakMap)                                                   │
│       │                                                                     │
│       ├─→ weakMap.has(obj)? → No                                           │
│       ├─→ 创建 newObj = {}                                                 │
│       ├─→ weakMap.set(obj, newObj)  // 记住：obj 已经在拷贝了               │
│       │                                                                     │
│       └─→ 拷贝 self 属性                                                   │
│               │                                                            │
│               └─→ deepClone(obj, weakMap)                                  │
│                       │                                                    │
│                       └─→ weakMap.has(obj)? → Yes! ✅                      │
│                           return weakMap.get(obj)  // 直接返回之前的结果    │
│                           不再递归，避免死循环!                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
