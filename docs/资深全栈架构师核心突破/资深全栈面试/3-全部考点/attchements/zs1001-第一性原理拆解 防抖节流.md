
# 第一性原理拆解：防抖函数

## 问题本质

**用户行为：** 短时间内触发多次事件（输入、滚动、resize）

**期望结果：** 只执行最后一次

**核心矛盾：** 如何判断"用户停止操作"？

## 第一性原理推导

### 1. 定义"停止"

```
停止 = 距离上次触发超过 N 毫秒
```

### 2. 实现逻辑

```
每次触发时：
  1. 取消之前的等待
  2. 重新开始等待 N 毫秒
  3. N 毫秒后执行
```

### 3. 最小实现

```javascript
function debounce(fn, delay) {
  let timer = null;  // 存储定时器ID

  return function(...args) {
    clearTimeout(timer);           // 取消上次的等待
    timer = setTimeout(() => {     // 重新等待
      fn(...args);                 // 执行函数
    }, delay);
  };
}
```

## 逐步推导过程

### 阶段1：最简单的延迟

```javascript
// 问题：每次都执行，没有"防抖"
function bad(fn, delay) {
  return function(...args) {
    setTimeout(() => fn(...args), delay);
  };
}

// 输入3次 → 延迟后执行3次 ❌
```

### 阶段2：加入取消机制

```javascript
// 关键：用变量存储定时器ID
function debounce(fn, delay) {
  let timer;

  return function(...args) {
    clearTimeout(timer);  // 取消上次
    timer = setTimeout(() => fn(...args), delay);
  };
}

// 输入3次 → 只执行最后1次 ✅
```

### 阶段3：处理 this 上下文

```javascript
function debounce(fn, delay) {
  let timer;

  return function(...args) {
    const context = this;  // 保存调用时的 this
  
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(context, args);  // 用正确的 this 调用
    }, delay);
  };
}
```

**为什么需要？**

```javascript
const obj = {
  name: 'Kiro',
  search: debounce(function(keyword) {
    console.log(this.name, keyword);  // 需要访问 obj.name
  }, 300)
};

obj.search('hello');  // 期望输出: Kiro hello
```

### 阶段4：立即执行模式

```javascript
function debounce(fn, delay, immediate = false) {
  let timer;

  return function(...args) {
    const context = this;
    const callNow = immediate && !timer;  // 首次立即执行
  
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null;  // 重置状态
      if (!immediate) fn.apply(context, args);
    }, delay);
  
    if (callNow) fn.apply(context, args);
  };
}
```

**使用场景：**

```javascript
// 普通模式：停止输入后搜索
const search = debounce(fetchData, 300);

// 立即模式：点击按钮立即提交，防止连点
const submit = debounce(submitForm, 1000, true);
```

## 时间轴演示

```javascript
const log = debounce(() => console.log('执行'), 300);

// 用户操作时间轴：
0ms:   log() → 启动定时器(300ms)
100ms: log() → 取消上次，重新启动(300ms)
200ms: log() → 取消上次，重新启动(300ms)
250ms: log() → 取消上次，重新启动(300ms)
// 用户停止操作
550ms: → 执行！（距离最后一次触发300ms）
```

## 完整实现 + 取消功能

```javascript
function debounce(fn, delay, immediate = false) {
  let timer;

  function debounced(...args) {
    const context = this;
    const callNow = immediate && !timer;
  
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null;
      if (!immediate) fn.apply(context, args);
    }, delay);
  
    if (callNow) fn.apply(context, args);
  }

  // 取消功能
  debounced.cancel = function() {
    clearTimeout(timer);
    timer = null;
  };

  return debounced;
}
```

**使用取消：**

```javascript
const search = debounce(fetchData, 300);

input.addEventListener('input', search);

// 用户离开页面时取消
window.addEventListener('beforeunload', () => {
  search.cancel();  // 避免内存泄漏
});
```

## 核心要素总结

```javascript
// 1. 闭包：保存状态
let timer;

// 2. 清除：取消上次
clearTimeout(timer);

// 3. 延迟：重新等待
timer = setTimeout(fn, delay);

// 4. 上下文：保持 this
fn.apply(context, args);
```

## 实际应用

```javascript
// 搜索框
const search = debounce(async (keyword) => {
  const results = await fetch(`/api/search?q=${keyword}`);
  renderResults(results);
}, 300);

input.addEventListener('input', (e) => search(e.target.value));

// 窗口 resize
const handleResize = debounce(() => {
  console.log('窗口大小:', window.innerWidth);
}, 200);

window.addEventListener('resize', handleResize);

// 滚动加载
const loadMore = debounce(() => {
  if (isBottom()) fetchNextPage();
}, 150);

window.addEventListener('scroll', loadMore);
```

**本质：** 用定时器 + 取消机制，将"连续触发"转换为"单次延迟执行"。
