# 总结

**投资者思维 = TDD 思维**

```
1. 先验证需求（做真题）
2. 最小化投入（聚焦高频）
3. 快速迭代（每周复盘）
4. 复用价值（博客 = 简历 = 面试）
5. 长期主义（博客 = 复利资产）

**核心公式：**

```
个人价值 = 技能 × 经验 × 成果 × 影响力

简历 = 成果可视化
博客 = 影响力杠杆
复习 = 技能提升
