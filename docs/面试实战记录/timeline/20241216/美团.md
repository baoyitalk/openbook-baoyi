题目2:字符串中的第一个唯一字符

给定一个字符串s，你需要找到它第一个不重复的字符，并返回这个字符的索引 。如果字符不存在，则返回-1。

### 备注

```
1 <= s.length <= 105

s 只包含小写字母

示例1

输入

s = "aabbcc"

输出

-1

示例2

输入

s = "abacabad"

输出

3

---

答案：

var firstUniqChar = function(s: string): number { const frequency: { [key: string]: number } = {}; // Count the frequency of each character in the string for (const ch of s) { frequency[ch] = (frequency[ch] || 0) + 1; } // Find the first unique character for (const [i, ch] of Array.from(s).entries()) { if (frequency[ch] === 1) { return i; } } return -1; };

```
