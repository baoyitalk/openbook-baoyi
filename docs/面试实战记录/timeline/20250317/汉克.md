# 面试项目应答记录（精简口语化，适配面试）

## 一、亚信科技（中国移动项目）

1. 项目难点：H5 需适配 APP 和小程序双端，通信规则不统一，且多业务线组件杂乱、性能卡顿。
2. 解决方法：自研 JSBridge 协议实现双端复用，封装统一组件库，结合接口聚合、懒加载优化性能。
3. 解决方案细节：自定义统一通信格式和回调机制，封装 H5 适配层自动判断运行环境，适配 APP 和小程序原生通信方式，增加超时、重试异常处理，实现一套 H5 代码双端复用。

## 二、神州数码（光大银行项目）

1. 项目难点：多系统接口差异大、数据格式不统一，千万级结算数据渲染卡顿。
2. 解决方法：设计统一数据适配层，开发 Node.js BFF 层，配合 SQL 索引优化和虚拟滚动。
3. 解决方案细节：适配层屏蔽各系统接口差异，BFF 层聚合多后端接口减少前端请求，SQL 索引优化提升查询速度，虚拟滚动解决大数据渲染卡顿，保障系统流畅运行。
