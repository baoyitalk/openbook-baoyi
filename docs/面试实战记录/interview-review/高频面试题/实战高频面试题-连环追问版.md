## A. 项目与跨端

### 1. 你最近项目最大的难点是什么？
Q1：你最近项目最大的难点是什么？  
A1：多端适配 + 性能。一个 H5 要跑 App WebView 和小程序，通信规则不一样，还要秒开。

Q2：你怎么拆这个问题？  
A2：拆三层：通信统一、组件统一、数据和加载优化。

Q3：通信统一具体怎么做？  
A3：自研 JSBridge 协议层，业务只调统一 API，底层按运行环境分发。

Q4：性能做了什么？  
A4：路由级拆包、懒加载、请求聚合、长列表虚拟滚动。

Q5：结果？  
A5：一套代码覆盖多端，迭代更快，首屏和交互明显更稳。

### 2. 为什么在有跨端框架时还要自研 JSBridge？
Q1：为什么不直接上现成框架？  
A1：现网有历史容器和协议，直接替换成本高、风险大。

Q2：自研价值是什么？  
A2：做协议适配层，业务层屏蔽端差异，改造最小。

Q3：会不会重复造轮子？  
A3：不是重造渲染引擎，只是补现网约束下的通信统一层。

Q4：怎么保可维护？  
A4：协议版本化、统一错误码、超时重试、降级和日志监控。

### 3. 你做过的性能优化真实案例？
Q1：你做过最有结果的优化？  
A1：首屏慢和列表卡顿。首屏做拆包+预加载，列表做虚拟滚动。

Q2：怎么验证有效？  
A2：看 LCP/FCP、接口耗时、渲染耗时和线上埋点。

Q3：团队收益？  
A3：用户体感更快，投诉下降，后续迭代沿用同套优化模板。

## B. React 核心

### 4. React 里你用得最深的点是什么？
Q1：最深的点是什么？  
A1：渲染性能和更新时机控制。

Q2：常用手段？  
A2：组件边界拆分、memo/useMemo/useCallback、虚拟列表。

Q3：踩过什么坑？  
A3：过度 memo，代码复杂但收益小。后来先定位瓶颈再下手。

### 5. 讲讲 React Diff 算法
Q1：核心思想？  
A1：同层比较、类型不同直接替换、列表靠 key 复用。

Q2：key 为什么重要？  
A2：key 稳定才能减少错位更新和无效重建。

Q3：对业务价值？  
A3：复杂列表更新更稳，重渲染更可控。

### 6. 为什么引入 Fiber？
Q1：老架构问题是什么？  
A1：更新不可中断，大任务会卡住主线程。

Q2：Fiber 解决什么？  
A2：任务切片，可中断可恢复，支持优先级调度。

Q3：业务体感变化？  
A3：输入、滚动等交互更顺，不容易整页卡死。

### 7. useEffect 常见用法和坑
Q1：useEffect 用来干嘛？  
A1：处理副作用：请求、订阅、绑定事件、DOM 操作。

Q2：依赖数组怎么定？  
A2：effect 里用到的响应式值都进依赖，避免闭包旧值。

Q3：怎么防泄漏？  
A3：cleanup 里取消订阅、移除监听、终止请求。

### 8. refs、context、props 区别
Q1：props vs context？  
A1：props 显式传值，context 适合跨层共享。

Q2：refs 用在什么场景？  
A2：拿 DOM 或保存不触发渲染的可变值。

Q3：context 能全替代状态管理吗？  
A3：不能，高频大状态全塞 context 会引发无关重渲染。

## C. 工程化与构建

### 9. webpack 和 vite 区别
Q1：一句话区别？  
A1：开发阶段 Vite 更快；复杂历史项目 webpack 更稳。

Q2：Vite 为什么快？  
A2：原生 ESM 按需加载，不走全量打包启动。

Q3：怎么选型？  
A3：新项目优先 Vite，重历史包袱项目保 webpack。

### 10. webpack 做过哪些优化
Q1：你做了哪些优化？  
A1：提速、减包、提缓存命中三块。

Q2：提速手段？  
A2：持久化缓存、多进程、收窄 loader 范围。

Q3：减包手段？  
A3：代码分割、按需加载、tree-shaking、依赖拆包。

Q4：缓存怎么做？  
A4：contenthash + runtime 拆分，提升长期缓存效果。

### 11. webpack 到 vite 迁移怎么答
Q1：迁移收益？  
A1：开发启动和热更新明显更快。

Q2：迁移风险？  
A2：插件兼容和构建行为差异。

Q3：怎么稳迁？  
A3：先 POC，再按模块灰度迁移，保留回滚路径。

## D. 性能与首屏

### 12. 首屏加载怎么优化
Q1：第一步做什么？  
A1：先测瓶颈，别盲改。看网络、接口、渲染谁最慢。

Q2：常见手段？  
A2：路由懒加载、关键资源预加载、图片懒加载、接口并行和缓存。

Q3：怎么验证？  
A3：看 LCP/FCP/TTI 和真实用户监控，不只看本地。

### 13. SSR 改造怎么讲
Q1：SSR 核心价值？  
A1：首屏更快可见，SEO 更友好。

Q2：改造关注点？  
A2：数据预取、同构边界、hydrate 一致性、缓存策略。

Q3：主要风险？  
A3：服务端压力和水合不一致，要有降级和监控。

### 14. 前端“秒开”怎么落地
Q1：你怎么定义秒开？  
A1：用户感知首屏快速可用，不是只看某个单指标。

Q2：组合拳是什么？  
A2：首屏瘦身、关键链路前置、骨架屏、接口聚合、缓存复用。

Q3：结果怎么汇报？  
A3：指标前后对比 + 业务指标（转化/停留/投诉）联动说明。

## E. 手写与算法

### 15. 手写防抖
Q1：防抖是什么？  
A1：高频触发时，只执行最后一次。

Q2：实现核心？  
A2：闭包保存 timer；每次先 clearTimeout 再 setTimeout。

Q3：追问立即执行？  
A3：加 leading/trailing 配置。

Q4：React 里注意点？  
A4：用 useMemo/useRef 固定函数引用，避免重建。

### 16. 手写 Promise.all / allSettled
Q1：Promise.all 行为？  
A1：全成功才 resolve，一失败立刻 reject。

Q2：allSettled 行为？  
A2：全部结束后统一返回，每项带状态。

Q3：实现关键点？  
A3：Promise.resolve 包装、计数收敛、结果按输入顺序回填。

### 17. 字符串第一个不重复字符
Q1：解法？  
A1：两遍遍历：先计数，再找第一个计数为 1 的字符。

Q2：复杂度？  
A2：时间 O(n)，空间 O(k)。

Q3：为什么不用双循环？  
A3：双循环 O(n^2) 不稳，哈希计数更高效。

## F. JS / TS / CSS 基础

### 18. 事件循环、宏任务、微任务
Q1：执行顺序？  
A1：同步 -> 微任务队列 -> 下一个宏任务。

Q2：常见微任务？  
A2：Promise.then/catch/finally、queueMicrotask。

Q3：为什么常考？  
A3：很多异步 bug 本质是执行顺序问题。

### 19. TS：interface 和 type 区别
Q1：怎么选？  
A1：对象结构都可，先遵循团队规范。

Q2：主要差异？  
A2：interface 可声明合并；type 更擅长联合交叉等类型运算。

Q3：实战建议？  
A3：公共协议偏 interface，复杂组合偏 type。

### 20. CSS：margin 塌陷 + 垂直居中
Q1：父子 margin-top 会相加吗？  
A1：不会，会外边距合并，取较大值。

Q2：怎么避免塌陷？  
A2：父元素加 padding/border，或触发 BFC。

Q3：垂直居中常用方案？  
A3：flex、grid、绝对定位 + transform。

Q4：!important 和行内样式谁高？  
A4：同层比较时，带 !important 的规则优先。

### 21. 虚拟 DOM 和真实 DOM
Q1：虚拟 DOM 是什么？  
A1：真实 DOM 的 JS 描述，不直接等于页面节点。

Q2：价值是什么？  
A2：先在内存算差异，再减少真实 DOM 操作。

Q3：一定更快吗？  
A3：不绝对，复杂更新场景收益更明显。

## G. Git 与协作

### 22. rebase 和 merge 区别
Q1：merge 是什么？  
A1：保留分叉历史，生成合并提交。

Q2：rebase 是什么？  
A2：改基线，让历史更线性。

Q3：怎么选？  
A3：本地整理提交用 rebase；公共分支集成用 merge。

Q4：风险点？  
A4：rebase 会改写历史，已推送分支要谨慎。

## H. 项目迁移与组件

### 23. 为什么从 Vue 切 React
Q1：切换原因？  
A1：不是谁更好，是团队和业务生态统一。

Q2：迁移成本怎么控？

### 24. 自己封装过哪些组件
Q1：封装过什么？

Q2：封装最看重什么？  
A2：交互统一、可配置、可复用。

Q3：如何保证维护性？  
A3：清晰 props/事件契约 + 最小示例文档。

## I. 网络与加载

### 25. 跨域怎么回答
Q1：为什么跨域？  
A1：浏览器同源策略限制。

Q2：常见方案？  
A2：CORS 主流，开发期用代理，JSONP 只适合简单 GET。

Q3：预检请求是什么？  
A3：复杂请求先 OPTIONS，服务端允许后再发正式请求。

### 26. 懒加载实现思路
Q1：懒加载分哪两类？  
A1：代码懒加载和资源懒加载。

Q2：代码懒加载怎么做？  
A2：动态 import + 路由级拆包。

Q3：图片懒加载怎么做？  
A3：IntersectionObserver 进入视口再加载。
