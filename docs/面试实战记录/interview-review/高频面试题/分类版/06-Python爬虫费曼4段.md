# Python爬虫高频面试题（费曼4段版）

> 统一模板：学习理解 -> 大白讲解 -> 漏洞点 -> 简短总结

## 1. get 和 post 区别
- 学习理解：`GET`主要用于查询，参数在 URL；`POST`主要用于提交，参数在请求体。
- 大白讲解：都能发请求，但 `GET` 更像“拿数据”，`POST` 更像“交数据”。
- 漏洞点：把“安全性”完全归因于 `POST`。
- 简短总结：`GET`查数据，`POST`交数据。

## 2. headers 请求头作用
- 学习理解：请求头用于告诉服务器“我是谁、我要什么、怎么接收”。
- 大白讲解：不带头部很容易被识别成脚本；加常见浏览器头能通过基础校验。
- 漏洞点：只改 `User-Agent`，忽略 `Referer/Cookie/Accept-Language`。
- 简短总结：请求头用于身份和协议协商，也是基础反爬绕过点。

## 3. cookie 和 session
- 学习理解：`cookie` 存客户端，`session` 存服务端，都用于维持状态。
- 大白讲解：cookie 像本地小票；session 像服务端档案，票上只写编号。
- 漏洞点：把 cookie 当敏感数据仓库。
- 简短总结：cookie 在前端，session 在后端，目标都是“保持登录态”。

## 4. requests 和 urllib
- 学习理解：都能发 HTTP 请求；`urllib` 内置，`requests` 更易用。
- 大白讲解：功能方向一致，差别主要在开发效率和可读性。
- 漏洞点：误以为两者“能力完全不同”。
- 简短总结：都能抓网页，`requests` 是工程主流。

## 5. 什么是反爬，常见手段
- 学习理解：反爬是网站限制自动化抓取的机制。
- 大白讲解：访问太快、行为异常、参数不合法就会被限流或拦截。
- 漏洞点：只会说“验证码”，漏掉频控、签名、设备指纹。
- 简短总结：常见反爬有频控、UA校验、验证码、签名校验、IP封禁。

## 6. IP 被封禁怎么处理
- 学习理解：高频访问会触发风控，需要降速和换出口。
- 大白讲解：同一个 IP 一直高频请求，系统会直接拉黑。
- 漏洞点：只换代理，不做请求节奏治理。
- 简短总结：限速 + 重试 + 代理池轮换。

## 7. XPath 和 BeautifulSoup 区别
- 学习理解：都用于解析 HTML，XPath 偏路径表达，BS4 偏标签遍历。
- 大白讲解：XPath 快且精准；BS4 上手快，写起来更直观。
- 漏洞点：页面结构变化后 XPath 脆弱。
- 简短总结：都能解析，XPath 更强表达，BS4 更友好。

## 8. aiohttp 异步爬虫
- 学习理解：异步 I/O 让请求并发执行，提高吞吐。
- 大白讲解：不是一个个排队等，而是“谁回来先处理谁”。
- 漏洞点：并发过高导致被封或本地资源耗尽。
- 简短总结：异步并发提升效率，但要限并发。

## 9. selenium 作用
- 学习理解：自动化浏览器，适合抓 JS 动态渲染页面。
- 大白讲解：代码操控浏览器点、滑、输入，拿到最终渲染数据。
- 漏洞点：把所有站都用 selenium，效率低且成本高。
- 简短总结：动态页面优先抓接口，兜底再用 selenium。

## 10. 静态网页 vs 动态网页
- 学习理解：静态页面数据常在 HTML；动态页面数据多由接口返回。
- 大白讲解：源码能直接看见数据多半是静态；看不见就去抓网络请求。
- 漏洞点：把“源码没有”误判为“无法爬取”。
- 简短总结：动态页核心是找真实数据接口。

## 11. 什么是抓包
- 学习理解：抓包是观察浏览器和服务器之间的请求响应。
- 大白讲解：目的不是偷数据，而是定位“真实接口 + 必要参数”。
- 漏洞点：只看 XHR，不看请求头和响应码。
- 简短总结：抓包是爬虫分析的起点。

## 12. JS 逆向
- 学习理解：当参数由前端 JS 动态生成时，需要复现生成逻辑。
- 大白讲解：接口可见但参数算不出来，请求就会失败。
- 漏洞点：忽略时间戳、随机数、环境检测。
- 简短总结：逆向本质是“复现前端签名过程”。

## 13. HTTP 和 HTTPS
- 学习理解：HTTP 明文传输；HTTPS 通过 TLS 加密。
- 大白讲解：HTTP 像明信片，HTTPS 像密封信。
- 漏洞点：把 HTTPS 当作“绝对安全”。
- 简短总结：HTTPS 提升传输安全与可信性。

## 14. TCP 三次握手
- 学习理解：建立连接前双方确认收发能力和序列号。
- 大白讲解：你能听见我吗 -> 我能听见你，你呢 -> 我也确认。
- 漏洞点：顺序说反，或说不清每次握手目的。
- 简短总结：三次握手用于建立可靠连接。

## 15. 爬虫数据存储方式
- 学习理解：按数据规模和查询需求选存储。
- 大白讲解：小量 CSV，业务分析进 MySQL，缓存去 Redis，文档类用 MongoDB。
- 漏洞点：一把梭全存 MySQL。
- 简短总结：存储选型看结构化程度和查询模式。

## 16. 网页乱码怎么处理
- 学习理解：乱码本质是编码解码不一致。
- 大白讲解：响应是 `gbk` 你按 `utf-8` 解，肯定乱。
- 漏洞点：只靠猜编码，不看响应头和页面声明。
- 简短总结：先识别编码，再正确解码。

## 17. 多线程和多进程
- 学习理解：I/O 密集偏线程/协程，CPU 密集偏多进程。
- 大白讲解：爬虫大多在等网络，线程或协程更划算。
- 漏洞点：线程开太多导致上下文切换成本高。
- 简短总结：I/O 用并发，计算用多进程。

## 18. JSON 是什么
- 学习理解：JSON 是轻量数据交换格式，常用于接口返回。
- 大白讲解：看起来像字典字符串，解析后才能当对象用。
- 漏洞点：JSON 字符串和 Python 字典混用。
- 简短总结：JSON 是接口世界的通用数据格式。

## 19. 爬虫完整流程
- 学习理解：分析目标 -> 发请求 -> 解析数据 -> 清洗入库 -> 监控重试。
- 大白讲解：先找接口，再抓数据，再把脏数据处理好并保存。
- 漏洞点：只会“抓”，不会“清洗和容错”。
- 简短总结：不是会抓就行，稳定链路才是工程能力。

## 20. 验证码处理方式
- 学习理解：图形码可 OCR/打码，行为验证码需要自动化与风控策略。
- 大白讲解：简单图形码可识别，滑块要模拟行为或走平台能力。
- 漏洞点：忽视合规与业务风险。
- 简短总结：验证码问题先评估成本、合规，再决定技术路径。
