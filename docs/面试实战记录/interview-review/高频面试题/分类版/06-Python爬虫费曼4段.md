# Python爬虫高频面试题（50题·费曼统一格式）

> 固定模板（每题一致）
> 1. 学习理解：底层作用 + 本质
> 2. 讲授大白话：面试口述
> 3. 漏洞卡点：容易卡住的点
> 4. 压缩总结：短句背诵

## 1、GET 和 POST 请求区别
1. 学习理解：GET偏查询，参数常在URL；POST偏提交，参数常在请求体。
2. 讲授大白话：GET像“取数据”，POST像“交数据”。
3. 漏洞卡点：把POST误认为绝对安全。
4. 压缩总结：GET查数据，POST提数据。

## 2、headers 请求头作用
1. 学习理解：请求头决定身份、来源、能力协商。
2. 讲授大白话：不带像机器直连，带齐更像真实浏览器访问。
3. 漏洞卡点：只改UA不改Referer/Cookie。
4. 压缩总结：headers是基础反爬门票。

## 3、cookie 和 session
1. 学习理解：cookie在客户端，session在服务端，目标是维持会话状态。
2. 讲授大白话：cookie是小票，session是后台档案。
3. 漏洞卡点：存储位置和安全边界记混。
4. 压缩总结：cookie前端票据，session后端会话。

## 4、requests 和 urllib
1. 学习理解：都能发HTTP请求；urllib内置，requests更易用。
2. 讲授大白话：功能方向一样，工程里requests更省事。
3. 漏洞卡点：误以为两个用途不同。
4. 压缩总结：都能爬，主流用requests。

## 5、什么是反爬，常见手段
1. 学习理解：网站限制自动化抓取，保护业务和数据。
2. 讲授大白话：你太快、太像机器，就被限流或拦截。
3. 漏洞卡点：只答验证码，漏掉签名和风控。
4. 压缩总结：反爬是限流+校验+风控组合。

## 6、IP 被封禁怎么解决
1. 学习理解：高频触发风控，需降速+换出口。
2. 讲授大白话：访问太猛会被拉黑，放慢并轮换代理。
3. 漏洞卡点：只换IP不控频。
4. 压缩总结：控频治本，换IP治标。

## 7、xpath 和 bs4 区别
1. 学习理解：都用于解析HTML；XPath表达强，BS4上手快。
2. 讲授大白话：XPath更精准，BS4更顺手。
3. 漏洞卡点：结构一变XPath失效。
4. 压缩总结：都能用，按复杂度选。

## 8、aiohttp 异步爬虫
1. 学习理解：协程并发提高I/O吞吐。
2. 讲授大白话：不排队，一个会话并发跑很多请求。
3. 漏洞卡点：并发开太大被封。
4. 压缩总结：异步快，但必须限并发。

## 9、selenium 作用
1. 学习理解：驱动浏览器执行JS，获取动态渲染结果。
2. 讲授大白话：像真人点页面，把最终显示的数据拿出来。
3. 漏洞卡点：静态页也滥用selenium。
4. 压缩总结：动态兜底用selenium，优先抓接口。

## 10、静态网页、动态网页
1. 学习理解：静态数据常在源码，动态数据常来自接口。
2. 讲授大白话：源码里看不到就去Network找真实API。
3. 漏洞卡点：源码没数据就以为不能爬。
4. 压缩总结：动态页核心是抓接口。

## 11、什么是抓包
1. 学习理解：观察请求响应，定位真实接口和参数依赖。
2. 讲授大白话：不是猜链接，是看浏览器到底发了什么。
3. 漏洞卡点：只看响应不看请求头。
4. 压缩总结：抓包是分析起点。

## 12、JS逆向
1. 学习理解：复现前端签名/加密参数生成逻辑。
2. 讲授大白话：接口看得见，但参数算不对就拿不到数据。
3. 漏洞卡点：忽略时间戳和环境检测。
4. 压缩总结：逆向本质是复现签名流程。

## 13、http 和 https
1. 学习理解：HTTP明文，HTTPS基于TLS加密并校验证书。
2. 讲授大白话：HTTP像明信片，HTTPS像密封信。
3. 漏洞卡点：把HTTPS当绝对安全。
4. 压缩总结：HTTPS更安全但非万能。

## 14、TCP 三次握手
1. 学习理解：建立连接前确认双方收发能力与序列号。
2. 讲授大白话：你能听见我吗？我也能听见你？好，开始传。
3. 漏洞卡点：顺序背反。
4. 压缩总结：三次握手建立可靠连接。

## 15、爬虫数据存储方式
1. 学习理解：按规模和查询需求选存储介质。
2. 讲授大白话：小量CSV，业务MySQL，缓存Redis，文档MongoDB。
3. 漏洞卡点：一把梭全进MySQL。
4. 压缩总结：存储选型看数据形态。

## 16、网页乱码怎么处理
1. 学习理解：编码和解码不一致导致乱码。
2. 讲授大白话：网页是gbk，你按utf-8读，肯定乱。
3. 漏洞卡点：只盲猜编码。
4. 压缩总结：先识别编码，再正确解码。

## 17、多线程、多进程
1. 学习理解：I/O密集常用线程/协程，CPU密集常用多进程。
2. 讲授大白话：等网络就并发，重计算才开多进程。
3. 漏洞卡点：场景说反。
4. 压缩总结：I/O并发，计算多进程。

## 18、json 是什么
1. 学习理解：JSON是接口常用数据交换格式。
2. 讲授大白话：看起来像字典字符串，解析后才能取值。
3. 漏洞卡点：字典和JSON字符串混用。
4. 压缩总结：JSON是接口世界通用格式。

## 19、爬虫完整流程
1. 学习理解：目标分析→请求→解析→清洗→入库→监控。
2. 讲授大白话：先找到接口，再抓，再把脏数据处理干净。
3. 漏洞卡点：只会抓，不会治理。
4. 压缩总结：稳定链路比一次抓取更重要。

## 20、验证码解决方式
1. 学习理解：图形码可OCR/平台，行为验证需自动化策略。
2. 讲授大白话：简单码识别，滑块要轨迹和行为模拟。
3. 漏洞卡点：只会一种方案。
4. 压缩总结：验证码是技术+风控综合题。

## 21、解释会话保持 requests.session()
1. 学习理解：session自动维护cookie，保持登录会话连续性。
2. 讲授大白话：登录一次，后面请求都带身份。
3. 漏洞卡点：以为和手动cookie完全等价。
4. 压缩总结：session自动带cookie，适合连续抓取。

## 22、Referer 作用
1. 学习理解：Referer标识来源页，用于防盗链与来源校验。
2. 讲授大白话：服务器要看你从哪页跳过来。
3. 漏洞卡点：和UA作用混淆。
4. 压缩总结：Referer解决“来源校验”。

## 23、Token 和 cookie 区别
1. 学习理解：Token是显式鉴权凭证；Cookie是浏览器自动携带会话票据。
2. 讲授大白话：Token像通行码，Cookie像自动小票。
3. 漏洞卡点：不清楚过期刷新机制。
4. 压缩总结：Token显式，Cookie隐式。

## 24、正向代理和反向代理
1. 学习理解：正向代理代理客户端；反向代理代理服务端。
2. 讲授大白话：爬虫换IP是正向，Nginx分流是反向。
3. 漏洞卡点：代理对象说反。
4. 压缩总结：正向藏客户端，反向护服务端。

## 25、为什么要加 time.sleep
1. 学习理解：控频降速，避免触发风控。
2. 讲授大白话：太快就像机器人，容易封。
3. 漏洞卡点：只提速不控节奏。
4. 压缩总结：sleep是最基础限流手段。

## 26、浅谈 robots 协议
1. 学习理解：robots是访问建议规范，不是技术强制。
2. 讲授大白话：网站提醒你别爬哪些目录。
3. 漏洞卡点：以为robots会硬拦截。
4. 压缩总结：robots是规范信号，不是防火墙。

## 27、json.loads 和 json.dumps 区别
1. 学习理解：loads字符串→对象，dumps对象→字符串。
2. 讲授大白话：loads进来，dumps出去。
3. 漏洞卡点：两个函数记反。
4. 压缩总结：loads解包，dumps打包。

## 28、爬虫 403 报错含义及解决
1. 学习理解：403是服务器拒绝访问，常因鉴权/头部/频率问题。
2. 讲授大白话：你到了门口，但门卫不让进。
3. 漏洞卡点：把403当404。
4. 压缩总结：403先查身份参数和行为特征。

## 29、404、500 报错含义
1. 学习理解：404资源不存在；500服务端异常。
2. 讲授大白话：404是地址错，500是对方崩。
3. 漏洞卡点：责任归属分不清。
4. 压缩总结：404看路径，500看服务。

## 30、什么是内网穿透，何时用
1. 学习理解：把本地端口映射到公网，便于回调接入。
2. 讲授大白话：让外网能访问你本机服务。
3. 漏洞卡点：不了解回调场景。
4. 压缩总结：内网穿透解决公网回调到本地。

## 31、什么是无头浏览器
1. 学习理解：无UI运行浏览器，适合服务器自动化。
2. 讲授大白话：看不见窗口，但功能基本一样。
3. 漏洞卡点：误以为功能缺失。
4. 压缩总结：无头是部署形态优化。

## 32、selenium 缺点
1. 学习理解：资源重、速度慢、自动化特征明显。
2. 讲授大白话：好用但贵，跑大规模不划算。
3. 漏洞卡点：只说优点。
4. 压缩总结：selenium适合兜底不适合全量。

## 33、xpath contains 模糊匹配
1. 学习理解：属性动态变化时，contains可做稳定匹配。
2. 讲授大白话：不写全属性，抓住固定片段。
3. 漏洞卡点：匹配太宽抓错节点。
4. 压缩总结：contains用于动态属性降脆弱。

## 34、什么是数据脱敏
1. 学习理解：对敏感字段遮蔽处理，降低泄露风险。
2. 讲授大白话：手机号身份证中间打码再流转。
3. 漏洞卡点：只谈采集不谈合规。
4. 压缩总结：脱敏是交付合规底线。

## 35、异步和多线程区别
1. 学习理解：异步是事件循环切换，线程是多执行流并发。
2. 讲授大白话：异步更省开销，线程更易接入。
3. 漏洞卡点：并发和并行混淆。
4. 压缩总结：异步省资源，线程改造快。

## 36、什么是浏览器指纹
1. 学习理解：设备与浏览器特征组合用于风控识别。
2. 讲授大白话：换IP也可能因指纹相同被认出来。
3. 漏洞卡点：只关注UA不关注指纹。
4. 压缩总结：IP一维，指纹多维。

## 37、mitmproxy 中间人抓包
1. 学习理解：代理层抓包并可改写请求响应。
2. 讲授大白话：所有流量先过你这，再决定放行或修改。
3. 漏洞卡点：和F12能力混淆。
4. 压缩总结：mitmproxy是可编程抓包中枢。

## 38、池化思想（IP池、线程池）
1. 学习理解：资源预创建和复用，提升稳定性。
2. 讲授大白话：准备一池资源轮流用，不临时造。
3. 漏洞卡点：只有池没有健康检查。
4. 压缩总结：池化=资源复用+治理。

## 39、网页 gzip 压缩乱码处理
1. 学习理解：压缩响应未解压就读文本会乱码。
2. 讲授大白话：先拆压缩包，再谈编码。
3. 漏洞卡点：和字符编码乱码混为一谈。
4. 压缩总结：先解压，再解码。

## 40、爬虫部署 Linux 注意点
1. 学习理解：关注无头、依赖、守护进程、日志监控。
2. 讲授大白话：本地能跑不代表服务器能跑。
3. 漏洞卡点：环境差异没处理。
4. 压缩总结：部署重点是稳定常驻运行。

## 41、什么是 cookie 池
1. 学习理解：维护可用登录态集合，分摊账号压力。
2. 讲授大白话：很多已登录账号轮流用，不反复登录。
3. 漏洞卡点：和IP池混淆。
4. 压缩总结：cookie池是身份层高可用。

## 42、爬虫规避滑块验证
1. 学习理解：行为模拟+轨迹拟真+必要识别能力。
2. 讲授大白话：不能匀速直线拖，要像真人。
3. 漏洞卡点：动作太机械必失败。
4. 压缩总结：滑块是行为风控对抗。

## 43、什么是 x-sign 加密参数
1. 学习理解：前端算法生成签名，服务端校验合法性。
2. 讲授大白话：请求要带“暗号”，不对就不给数据。
3. 漏洞卡点：忽略时效字段。
4. 压缩总结：x-sign是接口门禁钥匙。

## 44、增量爬虫和全量爬虫
1. 学习理解：全量重抓全部，增量只抓新增/变更。
2. 讲授大白话：全量全覆盖，增量更省资源。
3. 漏洞卡点：增量去重和更新时间策略不稳。
4. 压缩总结：日常增量，周期全量校准。

## 45、爬虫去重怎么做
1. 学习理解：唯一键判断，常用Redis集合/布隆+DB唯一索引。
2. 讲授大白话：先判重再入库，避免重复抓和重复写。
3. 漏洞卡点：仅用列表去重效率差。
4. 压缩总结：前置判重+入库兜底双保险。

## 46、为什么要 timestamp
1. 学习理解：参与签名、防缓存、防重放。
2. 讲授大白话：告诉服务器“这是新请求”。
3. 漏洞卡点：客户端时间漂移导致验签失败。
4. 压缩总结：timestamp是请求新鲜度证明。

## 47、什么是 CDN，对爬虫影响
1. 学习理解：不同出口命中不同边缘节点，风控策略不一。
2. 讲授大白话：同请求不同IP可能不同结果。
3. 漏洞卡点：忽略节点差异排查。
4. 压缩总结：CDN让同请求结果可能分叉。

## 48、爬虫合规风险
1. 学习理解：隐私采集、越权访问、商用售卖、高频压测都高风险。
2. 讲授大白话：能抓不等于能用，更不等于能卖。
3. 漏洞卡点：只谈技术不谈合规。
4. 压缩总结：合规先行，最小采集。

## 49、异步抓取 aiohttp 流程
1. 学习理解：会话复用→协程任务→事件循环调度→结果汇总。
2. 讲授大白话：一个会话扔很多任务，谁回来先处理谁。
3. 漏洞卡点：协程、线程概念混淆。
4. 压缩总结：会话复用+协程调度=高吞吐。

## 50、项目最大报错如何排查
1. 学习理解：分层排查：状态码→鉴权→IP网络→结构→入库。
2. 讲授大白话：先定位哪层坏了，再逐层排除，不靠猜。
3. 漏洞卡点：回答无顺序无闭环。
4. 压缩总结：排障靠分层和对比基线。
