# 07 JS核心必考（费曼一问一答）

> 适用：高频基础题、输出顺序题、手写题口述。

## Q1：事件循环到底在解决什么问题？
**A（费曼四段）**
1. 学习理解：JavaScript 是单线程，事件循环负责安排同步任务和异步回调的执行顺序。
2. 大白讲解：你可以把它理解成“一个人排队办所有事”。先把手上的同步任务做完，再清理微任务，最后处理下一轮宏任务，所以代码看起来像并发，实际是有顺序的切换。
3. 漏洞卡点：只会背“同步-异步”，但不会按队列规则判断输出顺序。
4. 压缩总结：事件循环本质是任务调度机制，决定异步代码先后。

## Q2：什么是宏任务？
**A（费曼四段）**
1. 学习理解：宏任务是事件循环每一轮取出的主任务，常见有 `setTimeout`、`setInterval`、I/O 回调。
2. 大白讲解：宏任务像“每轮只叫一个号的大窗口”。`setTimeout(fn, 0)` 不是立刻执行，而是排到下一轮宏任务，前面同步和微任务都要先跑完。
3. 漏洞卡点：把“0ms”误解成立刻执行。
4. 压缩总结：宏任务按轮次执行，定时器属于下一轮。

## Q3：什么是微任务？
**A（费曼四段）**
1. 学习理解：微任务是在当前宏任务结束后、下一个宏任务前必须清空的队列，常见是 Promise 回调。
2. 大白讲解：微任务像“本轮收尾清单”。同步执行完后，会先把所有微任务清空，才会进入下一轮宏任务，所以 Promise 回调常比 `setTimeout` 先执行。
3. 漏洞卡点：不知道微任务是“清空式执行”，导致顺序题判断错误。
4. 压缩总结：微任务优先于下一轮宏任务。

## Q4：闭包怎么讲才不空泛？
**A（费曼四段）**
1. 学习理解：闭包是函数和其词法作用域的组合，让函数在外层执行结束后仍能访问外层变量。
2. 大白讲解：可以把它理解成“函数带着一个背包”，背包里装着创建时能访问的变量，后面在哪执行都能拿到。
3. 漏洞卡点：只讲定义不讲代价，忽略闭包持有引用导致内存不释放。
4. 压缩总结：闭包用于封装和状态记忆，用不好会内存滞留。

## Q5：this 指向怎么 20 秒说清？
**A（费曼四段）**
1. 学习理解：普通函数的 `this` 由调用方式决定；箭头函数不绑定自己的 `this`。
2. 大白讲解：谁调用普通函数，`this` 就指向谁；`new` 指向实例；`call/apply/bind` 可强制指定；箭头函数直接继承外层。
3. 漏洞卡点：把箭头函数和普通函数混着讲，面试官会追问卡住。
4. 压缩总结：普通函数看调用者，箭头函数看外层。

## Q6：防抖和节流怎么区分场景？
**A（费曼四段）**
1. 学习理解：防抖保最后一次，节流保固定频率。
2. 大白讲解：输入框联想用防抖，用户停下来再发请求；滚动监听用节流，持续触发时按频率执行，避免每像素都计算。
3. 漏洞卡点：只会背概念，不会映射到真实业务场景。
4. 压缩总结：输入防抖，滚动节流。

## Q7：Promise 错误传播机制怎么讲？
**A（费曼四段）**
1. 学习理解：Promise 链中 `throw/reject` 会向后冒泡，直到被 `catch` 捕获。
2. 大白讲解：像流水线出错往后传，遇到 `catch` 才被接住；接住后如果返回正常值，后续链路会恢复正常流程。
3. 漏洞卡点：在 `catch` 里吞错却不处理，导致业务“假成功”。
4. 压缩总结：错误会冒泡，`catch` 决定兜底还是继续抛。

## Q8：深拷贝怎么答才像做过项目？
**A（费曼四段）**
1. 学习理解：深拷贝难点在边界类型和循环引用，不是只会 JSON 方案。
2. 大白讲解：`JSON.parse(JSON.stringify())` 会丢函数、`undefined`、`Date` 精度和 `Map/Set` 结构，遇循环引用还会报错。项目里要么用成熟库，要么手写时加 `WeakMap` 防循环。
3. 漏洞卡点：把 JSON 方案当万能解。
4. 压缩总结：先讲边界，再讲可落地方案。
