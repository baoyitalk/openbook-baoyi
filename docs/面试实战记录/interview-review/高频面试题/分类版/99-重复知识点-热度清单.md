# 99 重复知识点热度清单（面试加载优先级）

> 原则：答案允许重复；重复越多，说明越高频，优先背。

## S级（高频必刷）
- 跨端通信 / JSBridge 适配
- 首屏优化（拆包、懒加载、并行请求、缓存）
- React 性能（Diff/Fiber/重渲染控制）
- 项目价值证明（指标前后对比）

## A级（高频常追问）
- 渐进迁移（灰度、回滚、分批策略）
- 公共组件封装（边界、复用、规范）
- 事件循环（同步/微任务/宏任务）
- Promise.all / allSettled
- webpack vs vite

## B级（基础补位）
- TS：type vs interface
- CSS：margin 塌陷、垂直居中
- 跨域：CORS、预检、代理
- Git：rebase vs merge

## 使用方式
1. 每次整理题库，不去重答案。
2. 同一知识点在不同问题下重复出现，标记一次“+1”。
3. 复盘时先刷 S 级，再刷 A 级，最后补 B 级。
4. 每条追问链至少 5 次，按难度追加，最多 16 次。
