# 04 手写题与算法题（连环追问）

## 1. 手写防抖
Q1：防抖是什么？  
A1：高频触发场景下，只执行最后一次。

Q2：核心实现？  
A2：闭包保存 timer，触发时先 clearTimeout 再 setTimeout。

Q3：立即执行怎么处理？  
A3：加 leading/trailing 参数控制首尾触发。

Q4：React 里注意点？  
A4：用 useMemo/useRef 固定防抖函数引用。

## 2. 手写 Promise.all
Q1：行为是什么？  
A1：全部成功才 resolve，一个失败立刻 reject。

Q2：实现关键？  
A2：Promise.resolve 统一包装 + 计数 + 顺序回填。

Q3：边界情况？  
A3：空数组要直接 resolve([])。

## 3. 手写 Promise.allSettled
Q1：与 all 的核心区别？  
A1：allSettled 不短路，等全部结束再返回状态。

Q2：返回结构？  
A2：每项包含 status 和 value/reason。

Q3：面试官追问实用场景？  
A3：批量请求部分失败也要拿到完整结果时。

## 4. 字符串第一个不重复字符
Q1：怎么做？  
A1：两遍遍历，先计数再找首个次数为 1 的字符。

Q2：复杂度？  
A2：时间 O(n)，空间 O(k)。

Q3：为什么不用双循环？  
A3：双循环 O(n^2)，字符串长就不稳。

## 5. 手写封装 Hook
Q1：封装 Hook 的目标？  
A1：把重复状态和副作用逻辑抽出来复用。

Q2：怎么讲一个例子？  
A2：比如 useDebounce/useRequest，统一 loading、错误、重试。

Q3：面试官追问注意点？  
A3：命名规范、依赖正确、避免副作用泄漏。
