# 02 React核心与Hooks（连环追问）

## 1. React 你用得最深的点是什么？
Q1：最深的点？  
A1：渲染性能和更新时机控制。

Q2：常用手段？  
A2：组件拆分、memo/useMemo/useCallback、虚拟列表。

Q3：怎么判断优化有效？  
A3：Profiler + 线上埋点，不靠主观感觉。

## 2. 讲讲 React Diff
Q1：Diff 核心？  
A1：同层比较，类型不同直接替换，列表靠 key 复用。

Q2：key 不稳定会怎样？  
A2：节点错位、状态错乱、无效重渲染增加。

Q3：业务价值？  
A3：列表更新更稳，页面抖动更少。

## 3. 为什么引入 Fiber？
Q1：老架构问题？  
A1：大更新不可中断，容易卡主线程。

Q2：Fiber 带来什么？  
A2：可中断、可恢复、可按优先级调度。

Q3：用户侧感知？  
A3：输入和滚动更顺滑。

## 4. useEffect 常见追问
Q1：useEffect 干嘛用？  
A1：处理副作用：请求、订阅、事件绑定。

Q2：依赖数组怎么定？  
A2：effect 中使用到的响应式值都要进依赖。

Q3：怎么防内存泄漏？  
A3：cleanup 里取消订阅、移除监听、终止请求。

## 5. refs、context、props 区别
Q1：props vs context？  
A1：props 逐层显式传；context 跨层共享。

Q2：refs 主要用途？  
A2：访问 DOM 或保存不触发渲染的可变值。

Q3：context 能替代状态管理吗？  
A3：不能，高频状态全塞进去会导致无关重渲染。

## 6. 事件循环（React场景常追问）
Q1：顺序怎么说？  
A1：同步 -> 微任务 -> 宏任务。

Q2：为什么 React 面试常问这个？  
A2：异步状态更新和回调顺序都跟它有关。
