# 电商商品页 — Next.js 缓存与首屏性能面试演示

## 项目定位
面试演示项目，展示 Next.js App Router 四层缓存机制和首屏性能优化。

## 技术栈
- Next.js 15 (App Router)
- React 19
- 纯 JS（无 TypeScript）
- pnpm 管理
- 端口：3002

## 核心面试考点

### 1. Next.js 四层缓存
```
浏览器 → Router Cache（客户端）
       → Full Route Cache（服务端 HTML）
       → Data Cache（fetch 缓存）
       → 数据源（API/DB）
```

### 2. ISR (Incremental Static Regeneration)
- `fetch` + `next: { revalidate: 60 }` → 60秒内复用缓存
- `generateStaticParams` → 构建时预渲染商品页

### 3. 动态数据
- `cache: 'no-store'` → 跳过所有缓存，每次请求最新数据
- 购物车、评论等实时数据场景

### 4. 首屏性能指标
- TTFB / FCP / LCP / DOM Ready
- performance API 采集
- 传输大小分析

## 页面结构
| 页面 | 路径 | 说明 |
