# 开发者 Dashboard — Next.js SSR 面试演示

## 项目定位
面试演示项目，展示 Server Components、Suspense Streaming、Hydration Error 等 Next.js SSR 核心概念。

## 技术栈
- Next.js 15 (App Router)
- React 19
- 纯 JS（无 TypeScript）
- pnpm 管理
- 端口：3003

## 核心面试考点

### 1. Server Components
- 默认组件即 Server Component，async/await 直接获取数据
- 代码不发送到客户端，减少 bundle size
- 组件：Profile、RepoList、HeatMap、Notifications

### 2. Suspense + Streaming SSR
- 不同速度的数据源：50ms / 500ms / 800ms / 1200ms
- 每个异步组件用 Suspense 包裹，独立流式到达
- Skeleton fallback 骨架屏
- HTTP chunked transfer encoding

### 3. Hydration Error
- ThemeToggle：localStorage 服务端不存在
- TimeAgo：时间戳服务端/客户端不一致
- 解决方案：useEffect + mounted 状态 + suppressHydrationWarning

### 4. Server/Client Component 边界
- Server Component 可以 import Client Component ✅
- Client Component 不能 import Server Component ❌
- 通过 children prop 组合 ✅

## 组件结构
| 组件 | 类型 | 加载时间 | 考点 |
|------|------|----------|------|
| Profile | Server | 50ms | SC 基础 |
| Notifications | Server | 500ms | SC + CC 混合 |
| RepoList | Server | 800ms | Streaming |
| HeatMap | Server | 1200ms | Streaming 优先级 |
| ThemeToggle | Client | - | Hydration Error |
| TimeAgo | Client | - | Hydration Error |
