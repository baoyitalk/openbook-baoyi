# 万人通讯录 — 虚拟列表 + Fiber 时间切片实战

## 一、项目定位
面试演示项目，一个页面展示"暴力渲染 vs 虚拟列表"的性能对比，同时能讲清 React Fiber 时间切片原理。

## 二、数据
- 模拟 10000 条联系人数据（姓名、头像emoji、手机号、部门）
- 每行固定高度 60px

## 三、页面布局（左右对比）

### 左半边 — 暴力渲染模式
- 直接 `.map()` 渲染全部 10000 条 DOM
- 顶部显示：DOM 节点数、首次渲染耗时
- 滚动时明显卡顿

### 右半边 — 虚拟列表模式
- 手写 `useVirtualList` Hook，只渲染可视区 + 上下各 5 条缓冲
- 顶部显示：DOM 节点数、首次渲染耗时
- 滚动丝滑

## 四、核心实现（面试考点）

### 1. 手写 `useVirtualList` Hook
- 输入：`{ data, itemHeight, getItemHeight, containerHeight, overscan }`
- 输出：`{ visibleItems, totalHeight, offsetY, onScroll, scrollToIndex, containerRef, startIndex, endIndex }`
- 核心公式（固定高度）：`startIndex = Math.floor(scrollTop / itemHeight)`
- 动态高度：前缀和数组 `prefixHeights[]` + 二分查找定位 startIndex
- 滚动节流：`requestAnimationFrame` 节流，每帧最多 setState 一次
- 滚动定位：`scrollToIndex(index)` API，支持跳转到任意索引
- 资源清理：unmount 时 `cancelAnimationFrame`
- 用 `transform: translateY(offsetY)` 定位可视区内容

### 2. 性能指标面板
三种渲染场景，使用 `React.Profiler` 的 `onRender` 回调精确测量 `actualDuration`：

| 场景 | 触发条件 | Profiler phase | 暴力渲染 | 虚拟列表 |
|------|---------|---------------|---------|---------|
| 首次渲染 | 页面加载 | `"mount"` | ✅ 渲染全部 DOM，耗时长 | ✅ 渲染可视区 DOM，耗时短 |
| 搜索渲染 | 搜索框输入，data prop 变化 | `"update"` | ✅ 重新 .map() 全部匹配项 | ✅ 重新计算可视区 |
| 滚动渲染 | 滚动列表 | `"update"` | ❌ 不触发（纯 CSS overflow 滚动） | ✅ onScroll → setState → 重渲染可视区 |

其他指标：
- 当前 DOM 节点数（`document.querySelectorAll` 计数）
- 实时 FPS（独立 `FpsBadge` 组件，`requestAnimationFrame` 计算帧间隔，不污染父组件）
- 虚拟列表可视区范围（startIndex - endIndex）

防循环策略：
- 搜索渲染：`currentDataRef` + `lastRecordedDataRef` 双 ref 对比，只在 data 引用变化时记录
- 滚动渲染：ref 暂存最新耗时 + 500ms 防抖后 setState，避免高频循环
- 所有 setState 通过 `queueMicrotask` 延迟，打破 Profiler onRender → setState 的同步调用链

### 3. Fiber 时间切片演示（加分项）
- 一个按钮"模拟重渲染"：用 `startTransition` 包裹暴力列表的状态更新
- 对比：不用 `startTransition` → 输入框卡死；用了 → 输入框流畅
- 自然引出 Fiber 时间切片的讨论

## 八、面试话术要点
- "Fiber 是分期付款，虚拟列表是少买东西，两者互补"
- "虚拟列表的本质是用 JS 计算代替 DOM 数量"
- "startTransition 告诉 React 这个更新不紧急，可以被用户输入打断"
- "动态高度用前缀和数组 O(n) 预处理，二分查找 O(log n) 定位，比逐项累加高效"
- "滚动用 rAF 节流而非 setTimeout，因为 rAF 和浏览器渲染帧对齐，不会丢帧也不会多算"
- "scrollToIndex 本质是查前缀和数组拿到目标 offsetTop，然后设置 scrollTop"
